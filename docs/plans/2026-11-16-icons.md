# Icons package (friends release map, step 6)

## Context
On 2026-11-13 a prototype (branch `prototype/icons`, `c92c5c7`, never merged) settled how the dashboard's icons
should look. The results are recorded in `docs/plans/2026-11-05-friends-release-map.md` §6. This package builds
that look for real, so no prototype code ships: the switch bar, the five sets, the density modes, the
localStorage store, the statfeed page and the stubbed header actions all stay behind. The user chose to do icons
before controls drift; the map's §6 note gets updated to show that reorder.

What the build ends up with:
- Lucide icon + text on nav, action buttons, stat cards and tiles, match rows and markers. The Settings page and
  the Highlights cards stay text.
- Goal is Phosphor's regular `SoccerBall`. Crossbar hits and Aerial touches are hand-drawn on Lucide's 24 grid
  with a 2px stroke.
- The game's statfeed PNGs are removed, along with their THIRD_PARTY_NOTICES entry.
- The stood-out mark stays "!". The share card keeps plain tiles and gets a trend arrow on its stood-out line.
- Avg boost is `BatteryMedium` and Empty tank is `Battery`. Stat card labels align to the top.

Size is about 250–350 lines, which fits one session. Tier: Substantial (two new dependencies, about 20 files).

## Approach
**One icon module and explicit keys, no label lookup.** The prototype matched labels to icons
(`LABELS["Aerial goal awards"]`). That match would put an icon on the Highlights cards, which must stay text, and
it breaks without warning if a label is renamed. Instead, every card and tile gets an explicit `icon` key from its
data or call site. Anything with no key stays text.

- `src/web/logic/icons.ts` (new, types only): `export type IconKey = "goal" | "assist" | … | "crossbar" | "aerial"`.
  Logic modules import this type, so they stay free of React. This replaces `IconName` (`logic/recap.ts:71`) and
  `TrendIcon` (`logic/trends.ts:17`).
- `src/web/components/Icon.tsx` (new):
  - `const ICONS: Record<IconKey, IconComponent>`. Use named Lucide imports so the bundle tree-shakes. Goal is
    `SoccerBallIcon` from `@phosphor-icons/react`. Crossbar and aerial are hand-drawn SVGs copied from the
    prototype's `HAND_GAPS`. `Record<IconKey, …>` makes the compiler check that every key has an icon.
  - `Icon({ k, className, label? })`: decorative (`aria-hidden`) unless `label` is set, in which case it gets
    `role="img"` and `aria-label`.
  - `IconLabel({ k, children })`: icon + text in an inline-flex span with a 6px gap and a 16px icon. Used for
    nav, recap tabs, buttons and the back link.
  - The CSS for these goes in `Icon.module.css` (taken from the prototype's `.svg`, `.lbl`, `.lblIco`).
- Key table (taken from the prototype's `LUCIDE` map): recap `Gamepad2`, trends `TrendingUp`, friends `Users`,
  settings `Settings`, quit `Power`, newSession `CirclePlus`, share `Share2`, copy `Copy`, download `Download`,
  back `ArrowLeft`, flag `Flag`, overview `LayoutGrid`, matches `List`, score `Hash`, winRate `Percent`, shooting
  `Crosshair`, streak `Flame`, time `Clock`, overtime `Timer`, hardest `Gauge`, fastest `Zap`, boost
  `BatteryMedium`, supersonic `Wind`, empty `Battery`, assist `Handshake`, save `Shield`, shot `Target`, demo
  `Bomb`, mvp `Crown`, trendUp/trendDown `TrendingUp`/`TrendingDown` (share callout only). Goal, crossbar and
  aerial are listed above.

**Logic (TDD, red first where there's behaviour):**
- `logic/recap.ts`: `PER_GAME[].icon` becomes `IconKey`, never null (score → `"score"`). `ExtraCard` gains
  `icon: IconKey`: hardest, fastest, woodwork → crossbar, boost, supersonic, empty, aerial. `tilesFor` (ids
  `streak | ended | shooting | mvps`, `recap.ts:40`) gives streak → streak, shooting → shooting and mvps → mvp;
  `ended` stays text. `HIGHLIGHTS` gets no keys.
- `logic/trends.ts`: `METRICS[].icon` becomes `IconKey` for every metric (win → winRate, shooting, and so on).
- `logic/share-card.ts`: `stood` gains `dir: "up" | "down" | null`. The direction comes from the stood-out stat's
  `vs`. It's `null` for the hardest-shot fallback (`share-card.ts:79`), which has no `vs` and gets no arrow. This
  replaces the prototype's `text.includes("below")`, which drew an up arrow for the hardest shot.
- Tests, red first: add `dir` to the `shareCard(...).stood` assertions (`share-card.test.ts:96, 98, 102-105`).
  Update the PER_GAME/ExtraCard/tile expectations in `recap.test.ts`. The `METRICS` and key tables are constant
  data: the type check and `Record<IconKey, …>` cover them, and no unit test is added for them.

**Components:**
- `StatCard.tsx` / `Tile.tsx`: `icon?: IconKey | null` renders `<Icon k className={styles.ico}/>` in place of the
  `<img>`. `StatCard.module.css`: change `.label` to `align-items: flex-start`. Drop `object-fit` from the icon
  rules that now style SVGs: `StatCard.module.css .ico`, `Tile.module.css:12`, `Matches.module.css:20`,
  `MatchView.module.css:7`, `Overview.module.css:29` and `Trends.module.css:6`.
- `Header.tsx`: the nav links and the Settings link get `IconLabel`. `HeaderActions.tsx`: Start new session and
  Quit get `IconLabel`, and the real `onConfirm`s stay (don't copy the prototype's stubs).
  `ConfirmButton.tsx`: change `label` to `ReactNode` (it is only rendered, at line 81).
- `RecapPage.tsx`: the Overview and Matches & numbers tabs get `IconLabel`. `ShareCard.tsx`: the Share, Copy
  image and Download PNG buttons get `IconLabel`. When `view.stood.dir` is set, the callout gets a
  `TrendingUp`/`TrendingDown` icon in a `.cmark` span. Take only the prototype's colour, margin and
  vertical-align (not its font rule, which was for the glyph), with a 14px `.cico`.
- `Overview.tsx`: remove the PNG imports and the `ICONS` map. Pass `c.icon` through. The extra cards get
  `icon={c.icon}`. Highlights stays as it is. Match cards and the MVP marker use `<Icon k="mvp">`. `StoodOutMark`
  keeps "!".
- `Matches.tsx`, `MatchView.tsx`: the MVP marker uses `<Icon k="mvp">` and the left-early ⚑ glyph becomes
  `<Icon k="flag">` inside the existing `.flag` span, keeping its `title` and `aria-hidden`. Table headers stay
  as abbr text (icon-only was rejected). The back link becomes `IconLabel k="back"` with no "←".
- `PeriodHeader.tsx`: `<Icon k="mvp" label="MVPs">`, and the ⚑ in the left-early line becomes `<Icon k="flag">`.
  `MetricTiles.tsx`: remove the PNG map and pass `m.icon` through.
- `friends/zones.tsx`: the tiles get keys (Current/Best streak → streak, Time together → time, Overtime →
  overtime, MVPs → mvp, Goals → goal, Matches → matches). Biggest win and the playlist tiles stay text.

## Logging and failure points
This change is static rendering only: no I/O, no new failure paths, nothing to log. `Record<IconKey, …>` makes a
missing icon a compile error. The html-to-image share export gets one new inline SVG, which is covered by the
share e2e and a manual look at the PNG.

## Changes during the build
- The share card's stood-out line now reads "50% above 30-day avg" in place of "50% above your 30-day average".
  The arrow had pushed the worst-case card (`share-stress.spec.ts`) 17px over; hiding the arrow brought it back
  under, which confirmed the cause. The user picked the shorter wording over a smaller arrow or no arrow
  (2026-11-16). It matches the dashboard's "vs 30-day avg".
- The friend and pair pages' "← Friends" back link now uses `IconLabel k="back"`, the same as the match view's
  "All matches" link. The prototype hadn't touched it; the user asked for it to match (2026-11-16). The pager's
  "← Newer" / "Older →" stay as text.
- The share callout's arrow takes the `.cmark` class straight on the SVG (14px, accent colour), with no wrapping
  span or separate `.cico` class: one element does the job.

## Plan review
One round with the `plan-reviewer` agent (opus), 2026-11-16. Its verdict was that the approach is sound. All
findings are folded in above:
1. High: the hardest-shot callout has no `vs`. Fixed: `dir` is nullable, null means no arrow, with tests at
   `share-card.test.ts:96-105`.
2. Med: the `tilesFor` ids are streak/ended/shooting/mvps, not score/win%. Fixed: streak, shooting and mvp get
   keys. The resulting `recap.spec.ts:117` strict-mode break is added to Verification.
3. Med: there was no trends test for `METRICS.icon`, and no automated check that icons render. Fixed: constant
   tables rely on the type check, and a new e2e checks for an icon on a per-game card and none in Highlights.
4. Low: the flag-count locator wasn't named. Fixed: `svg.lucide-flag`.
5. Low: the README disclaimer must stay. Fixed: only README lines 76-77 are edited.
6. Low: the licence facts were confirmed (Lucide 1.72.0 ISC plus Feather MIT, Phosphor 2.1.10 MIT), and the
   versions are pinned with `--exact`.
7. Low: the `.cmark` font rule is dropped, and the proxy-port change is listed as not carried over.
8. Low: `PER_GAME.icon` is non-null, and the `object-fit` files are listed.
