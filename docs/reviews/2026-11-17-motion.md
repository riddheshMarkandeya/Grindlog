# Motion build review summary

Date: 2026-11-18. Plan and full Review log: `docs/plans/2026-11-17-motion.md`.

- Round 1: `/code-review high`, arch-reviewer (opus), security-reviewer, `/simplify`.
  - Security came back clean. 12 findings were fixed, 2 needed no fix and none were deferred.
  - The real bugs:
    - Settings segments showed two highlights: the picked label's own accent outranked the rule
      that hides it under the pill.
    - The rail's line stayed on the wrong row when rows arrived above the open match. The fix is in
      `useIndicator`, which now observes the group's children.
    - FriendPage's remove could still replace a click while a page transition held the old page.
      The plan's "dead code" departure was wrong, so it now uses `redirect()`.
    - `shouldRedirect` read the browser's escaping of `'` as the user moving on. Both sides are now
      normalised through `URL`.
    - Groups kept live during a transition but present on one side only cut instead of fading.
    - Placeholder data showed the old period's "No matches".
    - A resize restarted the line tween every frame.
  - Smaller fixes:
    - StrictMode logged false redirect skips.
    - The tween duration now comes from its token.
    - Rejections of the transition's `ready` that aren't a skip are now logged.
    - Doc nits.
  - `/simplify`: the view-transition timings became per-style custom properties, `useIndicator`
    skips writes when nothing moved, and `where()` is shared. The skipped suggestions reopen
    decisions the plan settled; the log says why for each.
- Round 2 (the changes since round 1): correctness, arch (sonnet), security. One regression was
  found: `<Redirect>`'s once-per-mount guard dropped a later target. It's now keyed on target and
  location. Three nits needed no fix.
- Round 3 (the changes since round 2): correctness, security. Clean.
- New regression specs, each seen red first: the segment label has no background under the pill;
  the rail follows a row inserted above it; the `'` case in `shouldRedirect`.
- Real browser (Chrome, seeded stack): every indicator group reaches `live` on its item, rise and
  crossfade run with the token timings (read through `document.getAnimations()`), and there were no
  console errors.
- Left for a manual check: the feel at full frame rate, the same under reduced-motion emulation, and
  the dialog close in Firefox.
