FAQ

Is it safe? Will it get me banned?

It uses the game's official Stats API: no injection, no memory reading.

Where does my data go?

It stays in %LOCALAPPDATA%\Grindlog. The app only goes online to GitHub, for updates and seasons.

Mac, Linux, console?

Windows only.

Steam or Epic?

Both. If the one-click setup can't find the file, the card shows the steps by hand.

Why does Windows warn me?

Windows warns on the first install only, because the app isn't code-signed.
